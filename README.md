Foram feitos 15 testes para cada algoritmo descartando os 5 primeiros de cada teste.

Conclusão:

Com base nos dados foi notado uma ineficiência no algoritmo BubblesSort e o SelectionSorte que tiveram os piores resultados, seus tempos crescem quadraticamente se tornando inutilizável para vetores grandes. Para os vetores menores o InsetionSort levou a melhor já o QuickSort provou ser mais eficiente em vetores maiores sendo mais rápido que os demais. Sendo assim concluo que o QuickSorte para vetores grandes é o mais indicado.
